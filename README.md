# TezParts — Threads-бот (v0: только черновики)

Telegram-бот, который ежедневно генерирует черновик поста для Threads (@tez.parts)
через Claude и присылает его в личный чат. Публикация — вручную: копируешь текст
и постишь сам.

Threads API сознательно не подключён на этом этапе (нужен Professional-аккаунт,
Meta Developer App и токены — отдельная история). Автопубликация и авто-ответы
на чужие посты добавятся отдельным шагом, когда/если это будет готово.

## Что бот умеет сейчас

- Раз в день (время задаётся в `.env`) сам придумывает идею и пишет черновик поста.
- Присылает черновик в Telegram с кнопками: 🔄 другой вариант / ✅ беру / 🗑 не то.
- `/draft` — сгенерировать черновик прямо сейчас, не дожидаясь расписания.
- `/ideas` — посмотреть бэклог ещё не использованных идей.
- `/idea <текст>` — добавить свою идею в бэклог вручную.
- `/history` — последние 5 черновиков и их статус.
- Хранит всё в SQLite (`data/bot.db`), чтобы не повторять одни и те же идеи.

## Что нужно, чтобы запустить

1. **Telegram Bot Token.** В Telegram напиши @BotFather → `/newbot` → следуй
   подсказкам → получишь токен.
2. **Свой chat id.** Напиши что угодно боту @userinfobot — он пришлёт твой id.
3. **Anthropic API key.** console.anthropic.com → создать ключ.

Впиши всё в `.env` (скопируй `.env.example` → `.env`).

## Запуск

### Docker (рекомендуется)

```bash
cp .env.example .env
# заполни .env
docker compose up -d --build
```

### Локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполни .env
python -m bot.main
```

## Дальше

Когда Threads API будет готов (Professional-аккаунт, Meta Developer App,
long-lived токен) — добавляется `threads_client.py` и кнопка "✅ беру"
меняется на реальную публикацию через API. Текущая архитектура (Post/ContentIdea
в БД, генератор черновиков отдельно от Telegram-хендлеров) рассчитана на это
расширение без переписывания с нуля.
