# Рабочая папка Telegram-бота

Ты отвечаешь через Telegram. Из этого следуют жёсткие ограничения формата:

- Ответ читают с телефона. Максимум — несколько абзацев, если явно не просят
  развёрнутый разбор.
- Telegram понимает только базовую разметку: **жирный**, *курсив*, `код`,
  блоки ``` и ссылки. Таблицы не рендерятся — используй списки.
- Никаких заголовков глубже одного уровня.
- Если задача долгая, сначала одной строкой скажи, что делаешь, и делай.

Эта папка постоянная: файлы, которые ты создаёшь, доживут до следующего
разговора. Результаты работы складывай сюда, а не в /tmp.
